# 异世界连接（Bunny 重生计划）

这是 Bunny 单 HTML 原型的渐进式 React/TypeScript 迁移工程。

当前状态：

- 已建立 React + TypeScript + Vite 骨架
- 已拆出手机壳、状态栏和双页桌面组件
- 已迁移原版 14 个应用入口
- 已迁移时间图片组件、时区选择与本地记忆
- 已加入桌面左右滑动、“整理”入口、长按编辑和鼠标/触摸自由槽位拖动
- 也支持先点图标、再点空位，方便触屏精确摆放
- 已迁移番茄钟及其原版统计数据兼容
- 已迁移角色档案、世界书和预设管理
- 已建立与绯界彼此独立的“小手机资料库”
- 角色支持备注名、用户人设、开场白、情景、对话示例、默认预设和历史长度
- 世界书支持文字导入、概率、关键词逻辑、适用角色和注入位置
- 预设支持提示词以及温度、Top P、最大输出、聊天历史和记忆数量
- 已加入 Bunny、穗穗机、锁雾机和常见角色卡 / 世界书格式导入适配
- 已建立 Context Builder，统一处理角色、预设、范围、关键词和手动世界书
- “设置”入口现可配置 OpenAI 兼容接口、API Key、模型与生成参数
- “微信”入口现为真实聊天窗口，会自动组合上下文并保存角色聊天历史
- 支持流式回复、停止生成、模型列表读取与按角色切换会话
- “记忆宫殿”已支持每位角色独立的长期记忆库
- 可分类、筛选、编辑、置顶、停用和删除记忆，并保存关键词与重要程度
- 聊天可按设定轮数自动提取结构化记忆，也支持手动立即整理
- 未来对话会检索相关记忆并自动注入上下文，重复记忆会合并更新
- 可选启用“关键词＋向量”混合检索，识别没有重复原词但意思相关的提问
- 向量索引保存在本机 IndexedDB，只增量更新发生变化的记忆
- 相册照片本体已迁入 IndexedDB，单张支持至 25 MB，并保留旧照片自动搬家
- 数据保险箱会同时备份和恢复 IndexedDB 照片，API Key 仍明确排除
- 已加入 PWA 安装清单与离线应用壳，手机端会铺满屏幕并去掉黑色外框
- 双页桌面支持手指跟随、边缘阻尼和松手吸附，滑动方式更接近真实手机
- 微信支持录制或选择语音消息，音频保存在 IndexedDB 并可随保险箱备份
- 已加入角色电话，通话继续读取角色、预设、世界书和记忆，挂断后写入时间线
- “美化”支持更换桌面壁纸，并开放桌面与聊天页面的作用域 CSS
- 自定义 CSS 会拦截脚本式内容和外部资源，也可通过 `?safe-style=1` 临时关闭
- Embedding 服务不可用时会自动退回关键词检索，不阻断正常聊天
- 其他应用仍按迁移计划逐间搬入

原始文件保存在相邻目录：


详细步骤见 [`docs/migration-plan.md`](docs/migration-plan.md)。

## 本地启动

如果只是体验兔兔，可以先生成单文件版：

```text
pnpm run build:standalone
```

然后双击 `standalone/直接打开-异世界连接.html`。

根目录的 `index.html` 是 React 工程入口，不能直接双击。需要继续开发时再运行：

```text
pnpm install
pnpm dev
```

本项目已连接到 `lingwangshu018/Benny`，`main` 分支会通过 GitHub Actions
自动部署 GitHub Pages。

## 独立手机资料库

“资料库”只保存这台小手机自己的角色、用户人设、世界书和预设，不依赖
绯界皇家图书馆。两边以后通过明确的导入、导出或连接功能交换资料，不会
因为修改其中一边而悄悄改变另一边。

## 向量记忆

在“设置 → 自动记忆”中开启“关键词＋向量混合检索”，填写兼容
OpenAI `/embeddings` 格式的模型名称，然后建立索引。Embedding 接口留空时，
会复用聊天接口地址。

向量记忆默认关闭。关闭时仍使用原有关键词记忆；接口出错时也会自动回退，
所以它是增强层，不是聊天的硬依赖。
